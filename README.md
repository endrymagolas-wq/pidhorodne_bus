# 🚌 Розклад автобусів: Тернопіль ↔ Підгородне
### Спеціально для Уляни: McDonald's (Мазепи) ↔ Нижня зупинка (село)

---

## 📁 Склад проекту

1. **`index.html`** — Інтерактивний мобільний веб-додаток (PWA):
   - ⚡ **«Живий» таймер зворотного відліку** до найближчого автобуса прямо зараз («через 12 хв»).
   - 🍔 Розрахунок часу біля **McDonald's** (вул. Мазепи / Майдан Перемоги) та прибуття на **Нижню зупинку**.
   - 🔄 Перемикач напрямків в один клік: «З Тернополя» ↔ «З Підгородного».
   - 🔍 Фільтри маршрутів (можна приховати №40 або вибрати конкретне село).
   - ⚠️ Попередження про те, що **№40 їде тільки на міське кладовище** і не доїжджає до Нижньої зупинки.
   - 📱 Працює офлайн без інтернету після першого відкриття!

2. **Графічні шпаргалки (PNG для галереї або шпалер телефона)**:
   - `ternopil_to_pidhorodne_mobile.png` — ТЕРНОПІЛЬ ➔ ПІДГОРОДНЕ (з часом біля McDonald's).
   - `pidhorodne_to_ternopil_mobile.png` — ПІДГОРОДНЕ ➔ ТЕРНОПІЛЬ (з часом на Нижній зупинці).
   - `rozklad_all_in_one.png` — Зведений розклад на один екран.

3. **`rozklad_pidhorodne_ternopil.pdf`** — Зручний PDF-документ (можна зберегти у Файли або Google Drive).

4. **`bot.py`** — Готовий Telegram-бот:
   - Кнопки: «🍔 Від McDonald's (зараз)», «🏡 З Нижньої (зараз)», «📅 Розклад», «⚠️ Про №40».
   - Миттєво рахує київський час та показує найближчі рейси з таймером.

---

## 🚀 Як користуватися та захостити

### Варіант А. Закинути на Hostinger (найпростіше і найзручніше):
1. Зайдіть у панель Hostinger ➔ **File Manager** вашого сайту.
2. Перейдіть у папку `public_html/` (або створіть там підпапку, наприклад `bus/`).
3. Завантажте файл `index.html` (і за бажанням `manifest.json`).
4. Надішліть посилання Уляні (наприклад, `yoursite.com/bus`):
   - **На iPhone**: натиснути «Поділитися» ➔ **«На екран "Додому"»**.
   - **На Android**: натиснути три крапки ➔ **«Додати на головний екран»**.
   Додаток з'явиться як справжня мобільна програмка з іконкою автобуса!

### Варіант Б. Картинки в телефон:
- Просто перешліть файли `ternopil_to_pidhorodne_mobile.png` та `pidhorodne_to_ternopil_mobile.png` Уляні в Telegram. Вона зможе зберегти їх у фото або додати у «Вибране».

### Варіант В. Запуск Telegram-бота:
1. Створіть бота в [@BotFather](https://t.me/BotFather) і отримайте токен.
2. Вставте токен у файл `bot.py` у змінну `TOKEN = "ваш_токен"`.
3. Запустіть:
   ```bash
   python bot.py
   ```
